# 이미지 / 영상 제작 가이드

현재 화면은 외부 이미지 없이 동작합니다. 아래 자료가 있으면 프로젝트의 실제 구현 모습을 더 잘 보여줄 수 있습니다.

| 우선순위 | 자료 | 파일 | 권장 크기 |
|---|---|---|---|
| 1 | 수신호의 실제 웹 화면 | mulsigye-cover.webp | 1600 × 1250 |
| 2 | 수신호 웹 + Android 실제 화면 합성 | mulsigye-devices.webp | 1600 × 1250 |
| 3 | 공개 가능한 SBOM 화면 또는 비식별 데모 | sbom-cover.webp | 1600 × 1250 |
| 선택 | 수신호 실제 이용 흐름, 8~15초 | mulsigye-demo.mp4 + 포스터 | 1600 × 1000 전후 |

수신호 이미지 두 장 중 하나를 커버로 고릅니다. 현재 모델은 프로젝트당 이미지/영상 하나를 메인과 상세에서 공유합니다.

## 구도와 용량

커버는 데스크톱 약 1.27:1, 모바일 약 1.16:1로 크롭됩니다. 중요한 내용은 중앙 80% 안에 배치합니다. 상세에서는 전체 이미지 비율로 보여줍니다. 큰 제목은 HTML에 있으므로 이미지 안에 반복하지 않습니다.

수신호에는 짙은 청록/네이비, SBOM에는 슬레이트/블루가 어울립니다. WebP 또는 AVIF를 우선하고, 이미지 한 장 300KB 내외를 목표로 하되 글씨 판독성을 우선합니다. 임의의 수치를 실제 성과처럼 합성하지 않습니다.

## 공개 범위

회사 고객 정보, 사내 URL, 계정, 비공개 패키지/취약점 정보는 포함하지 않습니다. 안전한 샘플 데이터의 별도 데모를 사용했다면 caption에 ‘샘플 데이터 기반 데모 화면’이라고 명시합니다. 단순 블러 처리만으로 식별 가능성이 없어졌다고 가정하지 않습니다.

## 적용

파일을 `public/media/`에 넣고 `src/content/portfolio.mjs`의 media를 설정합니다.

```js
media: {
  src: 'media/mulsigye-cover.webp',
  alt: '수신호의 저수지 현황과 권장 행동 화면',
  width: 1600,
  height: 1250,
  caption: '수신호 실제 웹 화면',
}
```

영상에는 `type: 'video'`, `src: 'media/mulsigye-demo.mp4'`, `poster: 'media/mulsigye-demo-poster.webp'`를 지정합니다. 소리는 생략하는 편을 권장합니다. 대사나 음성 정보가 있다면 자막 파일(VTT)과 track 마크업을 추가해야 합니다.

`npm run check` 후 데스크톱과 390px 화면을 확인합니다. 히어로 조형물, 빌드 비교, 인증 통합 개념도는 코드로 구현되어 따로 제작하지 않아도 됩니다.
