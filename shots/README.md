# 스크린샷 넣는 곳

이 폴더에 아래 파일명으로 이미지를 저장하면 포트폴리오에 자동으로 나타남

## 파일명

### 수신호 (KRC 공모전, 공개 프로젝트)

| 파일명 | 내용 |
|---|---|
| `krc-web-home.png` | 웹 메인. 수위 추세와 가뭄 단계 예측 |
| `krc-web-detail.png` | 저수지 상세와 권장 조치 안내 |
| `krc-android.png` | Android 네이티브 앱 화면 |


### SBOM 플랫폼 (사내 CoP)

| 파일명 | 내용 |
|---|---|
| `sbom-dashboard.png` | 대시보드. 오픈소스 자산 현황 요약 |
| `sbom-vuln-list.png` | 취약점 목록과 영향도 분류 |

## 권장 사양

- 형식: PNG
- 가로: 1200px 내외 (카드 안에서 축소되어 표시되고, 클릭하면 원본이 새 탭에서 열립니다)
- 용량: 장당 500KB 이하 권장
